AWS AMPLIFY ENVIRONMENT VARIABLES - PostgreSQL RDS
========================================================

⚠️ IMPORTANT: Ek-ek karke "Add" button se add karo!

Yeh variables PostgreSQL RDS ke liye hain. MongoDB ki jagah PostgreSQL use kar rahe hain.

---

Variable 1: DATABASE_URL
Key: DATABASE_URL
Value: postgresql://cyberprobes_admin:YOUR_PASSWORD@YOUR_ENDPOINT:5432/cyberprobes

⚠️ IMPORTANT:
- YOUR_PASSWORD ko apne actual password se replace karo
- Agar password mein special characters hain, toh URL encode karo:
  @ → %40
  ! → %21
  # → %23
  $ → %24
  & → %26
  
- YOUR_ENDPOINT ko apne RDS endpoint se replace karo
  Example: cyberprobes-db.xxxxxxxxxx.ap-south-1.rds.amazonaws.com

Example:
postgresql://cyberprobes_admin:MyPass%40123!@cyberprobes-db.abc123.ap-south-1.rds.amazonaws.com:5432/cyberprobes

---

Variable 2: NEXTAUTH_SECRET
Key: NEXTAUTH_SECRET
Value: cyberprobes-secret-key-12345678901234567890123456789012

⚠️ IMPORTANT: Minimum 32 characters hona chahiye
Generate karne ke liye PowerShell mein:
node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"

---

Variable 3: NEXTAUTH_URL
Key: NEXTAUTH_URL
Value: [YAHAN APNI AMPLIFY APP KA URL DAALO]

Example: https://main.d123456789.amplifyapp.com

⚠️ Note: Apni app ka actual URL use karo!

---

Variable 4: NODE_ENV
Key: NODE_ENV
Value: production

---

Variable 5: JWT_SECRET (agar needed hai)
Key: JWT_SECRET
Value: jwt-secret-key-cyberprobes-12345678901234567890

⚠️ IMPORTANT: Minimum 32 characters hona chahiye

---

STEPS TO ADD IN AWS AMPLIFY:
1. AWS Amplify Console → Your App → Environment variables
2. "Add variable" button click karo
3. Key aur Value paste karo
4. Save karo
5. Redeploy hone do (5-10 min)
6. Test karo: your-url.amplifyapp.com/auth/login

---

LOGIN CREDENTIALS (Production):
Email: admin@cyberprobes.com
Password: admin123

⚠️ Pehle admin user create karna hoga:
Browser mein jao: https://your-url.amplifyapp.com/api/setup-admin

---

TROUBLESHOOTING:

1. Connection Error:
   - Check karo security group mein 0.0.0.0/0 allow hai
   - Check karo Public access = YES hai
   - Check karo endpoint correct hai

2. Authentication Error:
   - Check karo password correct hai
   - Check karo password URL encoded hai (special characters)

3. Database Not Found:
   - Check karo database name correct hai (cyberprobes)
   - Check karo initial database name create karte waqt sahi diya
